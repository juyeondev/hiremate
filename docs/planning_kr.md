# HireMate — 제품 기획

## HireMate는 무엇인가요?

AI 기반 인터뷰 연습 웹 앱입니다.
사용자는 직무를 입력하고 AI가 생성한 질문에 음성으로 답변하며 점수와 피드백을 받습니다.

---

## MVP 정의

> **목표:** 사용자가 로그인 없이, 데이터베이스 없이, 페르소나 없이 오직 음성만으로 하나의 인터뷰 세션을 완료할 수 있다.
> 핵심 루프가 끝에서 끝까지 작동해야 합니다.

### MVP 화면

| 화면 | 설명 |
|---|---|
| 로비 | 앱 이름, 짧은 설명, 시작 버튼이 있는 랜딩 페이지 |
| 직무 입력 모달 | 직무명을 입력하는 텍스트 필드(예: "Frontend Developer"), 확인 버튼 |
| 캐릭터 선택 | 하나의 인터뷰어 캐릭터 선택 (MVP에서는 1명, 이후 추가 예정) |
| 인터뷰 화면 | AI가 말풍선으로 5개의 질문을 순차적으로 묻고 사용자는 음성으로 답변 |
| 결과 화면 | 총점, 질문별 분석, 짧은 AI 피드백, 다시하기 버튼 |

### MVP 화면 흐름

```
로비
  ↓ (시작)
직무 입력 모달
  ↓ (확인)
캐릭터 선택  ← UI는 여러 캐릭터를 지원하도록 준비, MVP에서는 1명만 사용 가능
  ↓ (선택)
인터뷰 화면
  ↓ (5개 질문 완료 후)
결과 화면
  ↓ (다시하기)
로비
```

### MVP 기능

- 세션을 시작하기 위해 직무명을 입력
- 캐릭터 선택 화면 (MVP에서는 1명, 구조적으로 이후 추가 가능)
- 직무명을 기반으로 AI가 5개의 인터뷰 질문 생성
- Web Speech API를 통한 음성 입력 (음성 → 텍스트)
- 각 답변을 AI가 평가 (점수 + 한 줄 코멘트)
- 결과 화면에 총점 및 답변별 분석 표시
- 다시하기 버튼으로 세션을 로비로 리셋
- 로그인 없음, 데이터베이스 없음 — 페이지 새로고침 시 상태 초기화

### MVP 명시적 제외 항목

- 인터뷰어 페르소나의 행동 차이 (MVP에서는 모든 캐릭터가 동일한 프롬프트 사용)
- 텍스트 입력 대체
- 피드백 PDF 다운로드
- 사용자 계정 / 히스토리
- 다국어 지원

## 단계별 계획

### Phase 0 — 설정 *(현재)*
- [x] 프로젝트 이름 정의: **HireMate**
- [x] GitHub 리포지토리 생성
- [x] Next.js 프론트엔드 스캐폴드 (`/frontend`)
- [x] FastAPI 백엔드 스캐폴드 (`/backend`)
- [x] Vercel (프론트엔드) + Railway (백엔드) 설정
- [x] 프론트엔드 ↔ 백엔드 연결 확인

### Phase 1 — MVP
*목표: 인터뷰 루프가 끝에서 끝까지 작동*

**프론트엔드**
- [ ] 로비 화면 (앱 이름 + 시작 버튼)
- [ ] 직무 입력 모달 (텍스트 입력 + 확인)
- [ ] 캐릭터 선택 화면 (그리드 레이아웃, MVP에서는 1명)
- [ ] 인터뷰 화면 (말풍선 + 음성 녹음기)
- [ ] Web Speech API 통합 (음성 → 텍스트)
- [ ] 결과 화면 (점수 + 피드백 + 다시하기)
- [ ] 세션 상태 관리 (인메모리, DB 없음)

**백엔드**
- [ ] API 1. 직무명으로 5개 질문 생성
- [ ] API 2. 하나의 답변 평가, 점수 + 코멘트 반환
- [ ] API 3. 전체 세션에 대한 종합 피드백 생성
- [ ] OpenAI `gpt-4o-mini` 통합
- [ ] `.env` 기반 API 키 관리

**완료 기준:** 사용자가 로비 → 직무 입력 → 인터뷰(5개 질문) → 결과 → 다시하기를 음성으로만 진행할 수 있다.
